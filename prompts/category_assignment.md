역할: 주식 용어를 PRD에서 승인한 고정 카테고리 중 하나로 분류한다.

입력:
- term
- definition

허용 카테고리:
- 주식 기초
- 시장/상장
- 가격/차트
- 거래/주문/결제
- 공시/기업행위
- 재무/회계
- 투자지표/밸류에이션
- 수급/투자자
- 배당/주주환원
- 리포트/실적 표현
- ETF/펀드
- 파생/구조화상품
- 채권/금리/환율
- 거시경제
- 기타

판단 기준:
- term의 표면 단어보다 definition의 실제 의미를 우선한다.
- 시장 구분·상장·종목 지위는 시장/상장으로 둔다.
- 시세 화면 값, 등락률, 차트, 기술적 지표는 가격/차트로 둔다.
- 주문·체결·호가·신용거래·결제 흐름은 거래/주문/결제로 둔다.
- 공시·증자·감자·합병·분할·자기주식은 공시/기업행위로 둔다.
- 재무제표 항목과 회계 개념은 재무/회계로 둔다.
- 계산·수익성·밸류에이션 지표는 투자지표/밸류에이션으로 둔다.
- 개인·기관·외국인·순매수·순매도는 수급/투자자로 둔다.
- 배당 정책·주주환원은 배당/주주환원으로 둔다.
- 실적 발표·컨센서스·목표주가·투자의견 표현은 리포트/실적 표현으로 둔다.
- ETF·ETN·리츠·펀드·집합투자기구는 ETF/펀드로 둔다.
- ELS·DLS·ELB·DLB·선물·옵션·스왑은 파생/구조화상품으로 둔다.
- 채권·회사채·국채·금리·환율·외환 흐름은 채권/금리/환율로 둔다.
- 물가·경기·GDP·인플레이션처럼 시장 환경을 설명하면 거시경제로 둔다.
- 여러 카테고리에 걸치면 사용자가 사전에서 가장 먼저 찾을 위치를 category로 둔다.
- 승인 카테고리에 자연스럽게 들어가지 않거나 주식 뉴스 큐레이션 목적과 거리가 멀면 기타로 둔다.
- 기타는 최종 카테고리가 아니라 다음 단계 제외용 임시 카테고리다.

출력:
- Return only valid JSON.
- JSON 외의 텍스트, 마크다운 코드블록, 추가 key, null 금지.
- JSON keys: category
- category는 허용 카테고리 값만 사용한다.

Few-shot 예시 1
입력:
term: PER
definition: 주가를 주당순이익으로 나눈 투자지표

좋은 출력:
{"category":"투자지표/밸류에이션"}

Few-shot 예시 2
입력:
term: 권리락
definition: 배당이나 증자 권리를 받을 수 없게 된 상태

좋은 출력:
{"category":"공시/기업행위"}

Few-shot 예시 3
입력:
term: 순매수
definition: 특정 투자자 집단이 판 금액보다 산 금액이 더 많은 상태

좋은 출력:
{"category":"수급/투자자"}

Few-shot 예시 4
입력:
term: ELS
definition: 주가지수나 개별 종목 주가를 기초자산으로 삼는 조건부 금융상품

좋은 출력:
{"category":"파생/구조화상품"}

Few-shot 예시 5
입력:
term: IRP이체신청

좋은 출력:
{"category":"기타"}
